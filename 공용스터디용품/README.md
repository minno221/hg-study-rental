# 스터디 용품 대여 사이트

학교/동아리용 공용 스터디 용품 대여 웹앱 (Next.js)

## 주요 기능
- **학생용 (`/`)**: 반/이름 입력 → 물품 목록 확인 → 대여 신청. 관리자가 업로드한 명단에 있는 사람만 신청 가능.
- **관리자용 (`/admin`)**: 비밀번호 로그인 → 학생 명단 업로드, 물품 등록/삭제, 대여 신청 승인·거절·반납 처리.

## 실행 방법
```bash
npm install
cp .env.local.example .env.local   # ADMIN_PASSWORD를 원하는 값으로 변경
npm run dev
```
브라우저에서 http://localhost:3000 (학생용), http://localhost:3000/admin (관리자용) 접속.

## 데이터 저장 방식 (MVP)
- 지금은 `data/db.json` 파일에 물품/명단/대여 내역을 저장하는 방식입니다 (별도 DB 설치 없이 바로 실행 가능).
- Vercel 등 서버리스 배포 환경에서는 파일 시스템이 재시작 시 초기화될 수 있어, 실제 운영 배포 시에는 Supabase/Firebase 같은 DB로 교체하는 것을 권장합니다. (요청 시 마이그레이션 도와드릴 수 있어요.)
