# 스터디 용품 대여 사이트

- 학생: 학번 + 이름 입력 → 대여 가능한 물품 확인 → 대여 신청
  (명단에 있는 학생만 가능, **같은 물품은 한 사람당 1개까지**)
- 관리자(`/admin`): 대여 신청 승인·거절·반납 처리 / 물품 등록·수정·삭제 / **엑셀로 학생 명단 올리기**

## 폴더 구조

```
app/
  page.tsx               학생 화면
  admin/page.tsx         관리자 로그인 + 탭
  admin/RentalsTab.tsx   대여 신청 관리
  admin/ItemsTab.tsx     물품 관리
  admin/RosterTab.tsx    엑셀 명단 업로드
  api/                   서버 API (student, rentals, items, roster, admin)
lib/                     공통 도구 (로그인, 검사, 엑셀 읽기 등)
prisma/schema.prisma     데이터베이스 구조 (학생 / 물품 / 대여)
scripts/build.js         배포할 때 표를 만들고 빌드
```

## 환경변수 (Vercel → Settings → Environment Variables)

| 이름 | 설명 |
| --- | --- |
| `ADMIN_PASSWORD` | 관리자 비밀번호 (**꼭 설정**. 길게 정할수록 안전해요) |
| `DATABASE_URL` 또는 `POSTGRES_URL` | Postgres 데이터베이스 주소 (Vercel Storage에서 연결하면 자동으로 들어와요) |

환경변수를 바꾼 뒤에는 **Redeploy** 해야 적용돼요.

## 엑셀 명단 양식

첫 줄에 `학번`, `이름` 칸이 있으면 돼요. 다른 칸(반, 번호 등)이 있어도 무시해요.

| 학번 | 이름 |
| --- | --- |
| 10101 | 홍길동 |

- 파일은 서버로 올라가지 않아요. 브라우저가 읽은 학번/이름만 데이터베이스에 저장돼요.
- 같은 학번이 이미 있으면 이름만 갱신하고, 새 학번은 추가해요.
- "엑셀에 없는 학생은 삭제"를 켜면 새 학기에 명단을 통째로 바꿀 수 있어요.

## 주의

- **학생 명단 엑셀 파일은 깃허브에 올리지 마세요.** (`.gitignore`에 엑셀/CSV는 막아뒀어요)
- 학생 확인은 학번+이름 일치로 해요. 로그인 비밀번호가 없는 간단한 방식이라
  다른 사람의 학번과 이름을 아는 사람은 그 학생 이름으로 신청할 수 있어요.
